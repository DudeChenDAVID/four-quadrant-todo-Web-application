# 四象限待办 · Four Quadrant Todo

一个基于 **React + Vite** 的简约待办事项 Web 应用。用四象限整理任务优先级，把时间花在真正重要的事上，减少无效思考和精力消耗。

![React](https://img.shields.io/badge/React-19-61DAFB?logo=react&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-6-646CFF?logo=vite&logoColor=white)
![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)

## ✨ 功能

- **四象限管理**：按重要性与紧急程度安排任务。
- **任务操作**：添加、删除、完成或恢复未完成，支持 Enter 快速添加。
- **拖拽调整**：将任务卡片拖到其他象限，重新安排优先级。
- **实时编辑与排序**：点击任务文字编辑并自动保存，拖拽可调整同象限内的顺序，插入线提示放置位置。
- **截止日期**：每条任务可单独选择日期，默认不设置；清空日期即可取消。
- **每日任务**：单独开启每日重复，第二天自动恢复未完成。
- **象限清空**：一键删除某个象限的全部任务。
- **本地保存**：任务与主题选择自动保存在浏览器中。
- **白天 / 夜晚模式**：浅色与深色界面，搭配柔和的任务卡片配色。
- **每日哲思**：接入一言在线 API 的诗词与哲学分类，每天获取并缓存一条；网络不可用时回退至内置的 14 条诗文名句。
- **响应式布局**：宽屏双列，窄屏单列。

## 🧭 四象限

| 象限 | 行动建议 | 示例 |
| --- | --- | --- |
| 着急且重要 | 优先处理 | 临近截止日期的关键工作 |
| 重要但不着急 | 安排时间 | 学习、长期规划、目标复盘 |
| 着急但不重要 | 尽快处理，控制投入 | 回复消息、临时事务 |
| 不着急且不重要 | 有空再做 | 整理文件、杂项 |

## 🚀 快速开始

### 环境要求

- [Node.js](https://nodejs.org/) 20.19+ 或 22.12+，推荐使用当前 LTS 版本。
- npm（随 Node.js 一起安装）。

### 安装与运行

下载或克隆本仓库，在项目根目录打开终端：

```bash
npm install
npm run dev
```

打开终端中显示的本地地址，默认是 **http://localhost:5173/**。如果端口已被占用，以终端显示的地址为准。

> 请通过 Vite 服务访问应用。直接双击源代码中的 `index.html` 无法运行 React JSX，会出现空白页。

### 构建与预览

```bash
# 生成生产环境文件，输出至 dist/
npm run build

# 本地预览构建结果
npm run preview
```

`dist/` 可以部署到静态网站托管服务。`preview` 用于本地预览，不作为生产服务器。

## 📝 使用说明

1. 在对应象限底部输入任务，按 **Enter** 或点击 **＋** 添加。
2. 点击任务左侧复选框切换完成状态，顶部会更新完成数量。
3. 拖动任务卡片到其他象限，调整任务分类。
4. 点击任务右侧 **↻ 每日** 开启或关闭每日重复；开启后按钮显示象限配色。
5. 点击 **×** 删除单条任务，点击象限右上角 **清空** 删除该象限全部任务。
6. 点击页面右上角 **夜晚 / 白天** 切换主题。

### 每日任务如何刷新？

- 按设备的**本地日期**判断是否进入第二天。
- 页面保持打开时会自动检查日期；关闭后再次打开，也会刷新每日任务。
- 刷新会将每日任务恢复为未完成，保留任务内容与所属象限。
- 普通任务不会自动重置，删除的每日任务不会再次生成。

### 在线金句来源

金句通过 [一言 API](https://hitokoto.cn/) 获取，使用诗词（`i`）与哲学（`k`）分类，无需 API 密钥。当天成功获取的内容会缓存在浏览器中，重复打开页面使用当天缓存；进入第二天后重新请求。请求失败或超过 6 秒时显示内置名句。在线分类中的内容并不保证每条都是古文，出处以接口返回的信息为准。

### 数据保存在哪里？

数据使用浏览器 `localStorage` 保存，无需登录，也不依赖后端。

- 任务存储键：`quadrant-tasks`。
- 主题存储键：`quadrant-theme`。
- 数据仅保存在当前浏览器、当前站点中，不支持跨设备同步。
- 清除站点数据会删除保存的任务。不同端口、`localhost` 与 `127.0.0.1` 属于不同站点，数据不会共享，建议固定使用同一个访问地址。
